BlueNova Backend Theme

A premium glossy metallic reskin of the Odoo 18 backend.

Deep Royal Blue and Electric Blue accents, chrome-silver gradients, glassmorphic panels, a persistent app sidebar, light/dark mode, and a Settings screen to recolour everything without touching SCSS.

Activate the app and the theme applies to the whole web client. Uninstall it and Odoo goes back to its stock look — no business data is touched.

Design system

  • Palette — Deep Royal Blue (#003087) primary, Electric Blue (#00AEEF) accents, cool silver / chrome gradients over tiered white surfaces
  • One token set — every colour, radius and shadow is a --cmt-* CSS custom property, so the whole theme recolours from one place
  • Typography — Inter and Poppins, bundled in-module (no CDN request)
  • Shape & elevation — rounded corners, soft multi-layer shadows, glossy glassmorphic cards, panels and dropdowns
  • Top navbar — restyled colours and typography
  • Left app sidebar replacing Odoo's apps dropdown, with 59 bundled app icons painted through a CSS mask: grey at rest, blue on hover, a stronger accent for the app you're in — matched by module name, so it keeps working in every language
  • Light / dark mode, switched from the sidebar footer, applied instantly and remembered per browser
  • Control panel styled as a page header, plus glassmorphic kanban boards with a 320px stage width and an accent spine on each card

Recolour it from Settings — no code, no rebuild

Settings → Theme Settings gives an admin live colour pickers for the core palette, top bar, search box, sidebar, active-app highlight, semantic colours and the auth pages, each with its own dark-mode counterpart where the surface needs one. An uploadable sidebar brand image and login background (light and dark) round it out. The whole palette can be exported as a JSON preset, re-imported later, or reset to the compiled defaults in one click. Changes apply on save via a page reload — no asset bundle rebuild, no server restart.

A themed landing dashboard

An optional KPI dashboard shows tiles for whichever apps are installed and readable by the current user — open opportunities, quotations, RFQs, posted invoices, open tasks, transfers to process, active employees. Every tile counts records as the logged-in user, never with elevated rights, so the numbers respect the same record rules as the underlying list views. It can optionally be set as the page a user lands on right after login.

The same look on login, signup and the public page

  • Login, signup and reset-password pick up the saved palette, an optional brand logo, and a tagline — including dark mode
  • Still themed if the website module is installed, since that module rebuilds those pages inside the site layout and the theme follows them there
  • An optional themed public page at / for anonymous visitors, off by default
  • It automatically stands down once website is installed, since that module owns / properly

Safe and reversible

The theme adds no new stored business data. Its only persisted state is a transient wizard used to import a colour preset, and a handful of ir.config_parameter rows and ir.attachment images that hold the chosen palette and uploaded brand art. Uninstalling the app removes all of that, and the backend returns to stock Odoo — nothing else in the database is touched.

Requirements

  • Odoo 18.0, Community or Enterprise
  • Depends only on web and base_setup
  • Optional — a CRM pipeline card restyle ships in the module but is inactive by default, so the theme never hard-depends on crm. It can be switched on by an administrator who has crm installed.

Known limits

  • Odoo's slide-in app menu on small screens (below md) is left as-is.
  • Dark mode covers the surfaces this theme styles plus the main list / form / kanban / dialog chrome. Odoo compiles most other colours into SCSS, so deeper corners — some reports, iframes and third-party widgets — can still show light patches.
  • The public home page has no drag-and-drop editing; it renders the company's own data plus the Settings tagline.
  • No fixed bottom footer bar and no floating action button.
